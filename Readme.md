<h1>Floreria Tienda 🌹</h1>

<p>
Aplicación web desarrollada en <strong>JavaScript, HTML y CSS</strong> que simula el carrito de compras de una florería.
Permite seleccionar ramos de flores, agregarlos al carrito, gestionar cantidades y calcular el precio total.
</p>

<h2>🚀 Funcionalidades</h2>
<ul>
<li>Agregar ramos de flores al carrito</li>
<li>Mostrar productos agregados dinámicamente en el DOM</li>
<li>Calcular el precio según la cantidad</li>
<li>Eliminar productos del carrito</li>
<li>Filtar ramos por categoria</li>
<li>Persistencia de datos usando <strong>Local Storage</strong></li>
<li>Alertas interactivas con SweetAlert2</li>
<li>Interfaz simple e interactiva</li>
</ul>

<h2>🛠 Tecnologías utilizadas</h2>
<ul>
<li>HTML5</li>
<li>CSS3</li>
<li>JavaScript</li>
<li>Local Storage</li>
<li>SweetAlert2</li>
</ul>

<h2>📚 Conceptos aplicados</h2>
<ul>
<li>Manipulación del DOM</li>
<li>Eventos en JavaScript (click, change)</li>
<li>Uso de arrays y objetos</li>
<li>Persistencia de datos en el navegador</li>
<li>Uso de librerías externas para mejorar la experiencia de usuario</li>
</ul>

<h2>🎯 Objetivo del proyecto</h2>
<p>
Practicar conceptos fundamentales de JavaScript para desarrollo web,
simulando un caso real de comercio electrónico.
</p>

<h2>▶️ Cómo ejecutar el proyecto</h2>
<ol>
<li>Clonar el repositorio</li>
<li>Abrir el archivo <strong>index.html</strong> en el navegador</li>
</ol>
